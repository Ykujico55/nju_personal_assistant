# 声明式组合工作流

本扩展只发布标准 WorkflowProvider 槽，不发送邮件、不操作浏览器、不提供 JavaScript。宿主依次解析 ask/tool/archive 节点，版本和来源保留在检查点，所有工具经过 Gateway。邮件和最终网页提交分别审批；UNKNOWN 停止并等待对账。

工具版本固定为 nju.smail 0.2.0、personal.knowledge 0.1.0、nju.ehall 0.1.0；版本或配置不符会暂停，不自动升级。安装、启用必须先经本机材料预览确认，本轮未安装到原助手。

字段缺失、资料未知时由用户补充，不能捏造。邮件正文由用户编辑；模型可在独立披露许可下协助提出草稿。F07 正式目标/载荷/材料/后果和权威预览未验收，事务填写与最终提交默认不可用。此处的声明和模拟节点验证不代表真实流程验收。
