# TUI 工作台使用指南

## 回复结果未确认的诊断（2026-11-09）

新请求若显示 CHAT_RESULT_UNKNOWN，未完成回复区会同时显示固定原因、阶段、耗时、原故障编号与本次HTTP请求编号。可滚动查看完整信息；不会显示异常原文或凭据。“重试原请求”只核对既有回执，不重新调用模型；旧请求无诊断时不会补造原因。

若仅原纯回复仍在STREAMING，可点“放弃未完成回复”；不适用于任务创建或外部动作UNKNOWN。当前后台已加载修复，已开的TUI需先妥善处理原请求，再退出重开。当前实例未冻结、Worker在线；下文安装时冻结记录是历史状态。详见[诊断报告](CONVERSATION_DIAGNOSTICS_2026-11-09.md)。

## 统一实例工作区（WORKSPACE.1 已安装，待终端人工检查）

2026-11-09已按本人授权安装 personal.files 0.1.1 / personal.knowledge 0.1.7，原目录已迁移绑定，配置 APPLIED、索引 READY；后台在线并保留手动冻结。证据见[安装记录](WORKSPACE1_INSTALL_2026-11-09.md)。下文首次迁移步骤供其他旧实例参考，当前实例无需重复。

新版工作台“设置”页提供 **编辑工作区 / 应用工作区 / 读取状态**。工作区是整个实例的目录授权来源；切换对话或任务不会另建授权。首版只有 `workspace_id: "instance"`，可包含多个互不嵌套的目录根，不包含多项目选择、虚拟文件系统或权限继承。

1. 点“编辑工作区”，填写以下非秘密 JSON，使用本机实际存在的绝对路径：

   ```json
   {
     "workspace_id": "instance",
     "roots": [
       {"key": "personal", "label": "个人资料", "path": "D:/Notes", "mode": "read_write"}
     ]
   }
   ```

2. 核对目录和权限后保存。`read_only` 允许读取，`read_write` 允许文件插件在该根内新建与修改；删除仍遵循插件本人确认规则。保存只产生 **已保存，待生效**，不会自动切换运行中的目录。
3. 点“应用工作区”，核对当前已保存内容后确认。应用绑定保存稿摘要；另一窗口修改后旧确认会被拒绝，需重新读取。各运行副本完成切换后才显示 **已生效**；**应用中** 或 **待生效** 不代表同步完成。没有运行消费者时不会虚报已生效。
4. 首次迁移已有插件时，需先安装支持此功能的候选版本；在“扩展 → 配置”中移除各自的 `roots`，添加 `"workspace_binding": "instance"`，保留插件专用参数，再分别保存并应用插件配置。现有独立根不会被静默迁移。此后日常目录切换只编辑并应用一次共享工作区，所有绑定插件使用同一来源。
5. **已生效不代表索引已就绪。** 应用配置后知识插件自动建立新索引；运行状态已生效不代表索引已完成，应以知识概览的索引状态和失败原因为准。指定文件直读不依赖旧索引。原文件写入计划需重新预览，未知结果、历史回执及旧任务工具快照不会被清除或自动重试。

将 `roots` 保存为 `[]` 并应用，可撤销所有工作区目录；只保存空列表不会撤销仍在使用的授权。向对话发送路径不会自动增加授权。宿主控制目录、凭据目录、插件代码和状态数据库不得放入授权根。这里是工具链路的授权边界，扩展仍是当前系统用户信任的代码，不是操作系统沙箱。

保存后若回执丢失，工作台不会盲目重放配置覆盖命令；请重开工作台读取当前配置并核对。“应用”的原摘要请求可安全核对重试，但不会绕过后来保存稿的冲突保护。当前原实例已完成安装和启动；后续升级仍需按材料确认流程执行。以下较早日期的部署状态是历史记录，当前状态以本节及安装记录为准。

## 实例知识库与自动对话（2026-11-06）

目录只需在当前实例的知识扩展配置中设置一次 `roots`；授权目录、持久索引和扩展状态属于整个实例，与任务 ID 无关。换任务或点“新对话”不会重新绑定目录，也不会清除索引。正文检索可复用 personal.knowledge 0.1.1；“有哪些文件／路径是否已配置”的目录概览由0.1.2及以后版本提供。源码变更不会自动替换已安装插件。这里绑定的是允许读取的资料目录，不是把整个磁盘或系统工作目录开放给模型。

后台及 TUI 重启加载本轮源码后，在已有 automatic 模型处理配置下，“对话”会按当前消息处理：

- 普通问题：直接流式回答，例如“解释一下二叉树”。
- 资料问题：选用当前实例已启用的 ContextProvider 检索，回答后显示来源及定位，例如“根据知识库的数据结构资料，解释树的遍历”。不需要先新建任务或每次 reindex。
- 执行请求：例如“为授权目录重建索引，然后整理一份摘要”，自动创建持久任务，由现有 Worker 领取。聊天中显示任务编号与创建时状态，侧栏更新关联任务状态；到“任务”页可查看详细结果、追加输入、取消和排序。任务排队不代表完成；冻结或 Worker 离线仍需本人处理原实例状态。

“Agent 任务”按钮仍可显式建任务；模型路由可能误判意图，不能声称所有自然语言均识别正确。缺少必要目标时先追问；“如何做”“先讨论、不要执行”应作为问答。最终外部发送/提交继续使用原精确审批，未知结果不自动重发。

知识检索读取已授权目录的有效索引片段，不是任意文件浏览/编辑器。首次配置后若尚无索引，明确让助手建立索引；没有命中不代表目录为空。0.1.2 的 knowledge.workspace 另行提供授权目录的有界文件元数据清单：无需先建立索引，不读取正文，标明目录不可用/清单截断/索引状态未知。它不等于正文检索；中文短词全文召回边界仍保留，本轮不改分词器。不会为普通问答默认读取所有扩展；仅查询模型从已启用目录选中的只读提供者，失效/SECRET证据不进入模型。读取失败和无结果会明确显示。

每轮先做一次有界意图判断；资料/普通回答再真实流式生成，实际两次用量均计入模型审计。会话 Token 只累加两次均实际报告的计数，缺失计数不估算为0。全过程660秒上限、10秒心跳，断流保留原请求。原键重试只查回执；已确定的任务创建可以恢复而不重复建任务，也不重复调用模型。

若回复明确达到模型输出上限、被内容过滤或模型拒绝请求，界面显示具体错误并保留输入；不将片段当作完整回答，不自动重发。真正断流/超时仍显示“结果未确认”，先用“重试原请求”只读核对。若后端确认该命令已进入纯回复阶段，可点“放弃未完成回复”结束这条等待，再编辑/重新发送；不会删除原命令、创建任务或把片段加入已确认历史。仍在意图分流、准备建任务，以及任务/外部动作的未决结果不能用这个按钮绕过。旧版留下的 STREAMING 回复也适用；正在生成的迟到回复会被版本检查拒绝覆盖。

manual 披露模式暂保留原“纯问答 + 披露预览”，不会未经许可把新检索资料交给模型。当前已授权 automatic 的原 profile 无需再次填写密钥或更改目录。手机 PWA 仍为任务交互入口，本轮自动对话入口在本机 TUI。

本轮不自动重启原实例、不恢复旧 PAUSED_SAFETY 任务、不安装扩展；旧任务仍可在任务页查看。全系统重启方式沿用本指南原有启动命令。

## 对话与执行

输入框支持本地命令：/help、/tasks、/extensions、/settings、/new、/ask、/agent、/usage。/ask 与 /agent 仅切换发送模式，/usage 显示已读取用量；命令本身不会调用模型。未知命令会提示并保留输入。对话使用终端安全的Markdown显示，控制字符被过滤；不执行模型提供的命令或链接。

列表刷新保留当前选中项与未变化任务的阅读位置。服务连接、冻结状态、Worker在线状态分别展示，连接Admin成功不等于任务Worker在线。设置页读取失败不影响用量与操作回执读取；配置版本冲突后使用“重新加载”，本地有修改时会先确认放弃。


“问答”适合解释、讨论、日常问题，支持最近12条问答的上下文。当前原实例已由本人明确选择 PA_MODEL_DISCLOSURE_MODE=automatic：点击发送即交给已配置的 DeepSeek，聊天及 Agent 读取的授权个人资料不再逐次弹出模型披露确认。宿主仍生成绑定实际字段/接收方的持久许可，记录 automatic 来源，SECRET 硬阻断和外部动作审批不变。其他未配置实例默认 manual，保留逐次披露确认。

DeepSeek/OpenAI 兼容模型的 TUI 问答使用真实流式增量输出；未完成文字明确标注，只有最终回执才加入对话历史及会话Token统计。断流/取消保留原请求，只允许同键查询，不重新调用模型。问答没有工具，回复不代表动作已执行。Agent 结构化规划、任务最终消息和手机页面本轮没有改成逐Token输出；未实现stream接口的旧模型只返回一次最终结果，不模拟打字。TUI退出后本地聊天历史结束，结果回执和审计由宿主保存。

“Agent 任务”把自然语言目标交给宿主。例如：

- “在授权的个人知识目录中查找我的简历并列出候选。”
- “使用插件开发工作区写一个简单计算器，先完成候选与测试。”
- “整理本地招聘名单，生成投递计划，先不要投递。”

若此前已有问答，发送 Agent 任务时直接携带本次目标和完整带角色边界的参考对话，不再增加创建确认弹窗。总长度超过10000字符会拒绝并保留输入，需主动精简或新建对话。历史助手回答不等于动作已执行，也不等于外部动作获批。

宿主将已启用扩展的工具目录交给规划器，模型选择工具后经原 Runtime → Tool Gateway → 扩展执行链调用。不需要手写具体插件调用；没有对应能力时应等待补充或明确失败，不自动下载/安装插件。任务页显示状态、消息、当前阶段和待执行工具标识。该投影不是完整永久调用日志，短暂步骤可能发生在刷新间隔内。

任务页可追加消息、确认精确模型披露、继续处理。追加消息不会自动继续；已终结任务应另建任务。R2 外部动作仍需原权威预览的一次性审批，TUI 本轮不复制这套审批材料页面，请在已有助手PWA完成；UNKNOWN 必须对账，普通继续不能绕过。

## 任务队列管理与列表面板

任务页现在提供“上移／下移／置顶／移除”。先点击任务，或用方向键移动后按 Enter 选定，再按对应按钮；“顺序”列表示当前到期待领取作业的位置，“—”表示当前没有这样的作业。排序会改变 Worker 实际领取顺序，并保存到数据库；不会打断正在执行的任务、提前触发未来计划或重新执行 UNKNOWN 动作。并发变化会拒绝旧版本，刷新后重新选择。光标指向的行与详情任务不一致时，排序/移除按钮会禁用，避免误操作另一任务。

“移除”确认后会取消未终结任务及尚未领取的作业，并从工作台列表隐藏；终结任务只隐藏。原任务、消息、审批、执行记录和幂等回执仍保留，手机任务历史与原任务 API 仍可查看。模型思考/材料准备中的取消也会停止等待，让 Worker 继续处理其他任务。未决外部动作显示“待对账”，不可移除或调序；如果取消后才发现外部结果未知，该任务会重新出现在列表中。

WAITING_USER（待补充）、WAITING_APPROVAL（待审批）和暂停状态已经退出当前执行，不会一直占用 Worker；需要输入时保留任务，不自动删除。无法启动的任务会明确失败；重复无进展和活动时长熔断仍保留。

本轮调整的是整个任务／扩展列表面板：随窗口尺寸增加显示行数，名称列自适应，状态和顺序在 80 列终端也可见。定时刷新只更新变化内容，保留选中项及当前滚动位置；没有加粗滚动条。代码生效需按下方步骤重启后台和 TUI，本轮未自动重启或解冻原实例。

## 扩展与配置

扩展页同时列出已发现源码和实际安装记录。DISCOVERED 显示为“未安装（已发现源码）”，不能直接启用；先填写源码路径并预览/确认安装。安装后才能启用。FAILED 同时显示 diagnostic_code；缺安装状态在接口直接返回409 EXTENSION_NOT_INSTALLED，不再制造无效异步启用操作。提供静态预览后的安装/升级、启用、禁用、卸载以及JSON配置编辑。预览后必须再次确认精确材料；取消不会安装。扩展是本机可信代码，独立venv/Worker只隔离依赖和崩溃。管理操作返回operation ID后轮询终态，不把202当作成功完成。

配置编辑会展示宿主返回的配置Schema和当前配置，先编辑再明确确认保存。现有扩展配置接口没有幂等回执；若保存结果未知，TUI禁止重发，重新打开后只读核对实际值，避免覆盖另一客户端的新配置。保存不会重启扩展。

设置页可修改模型名、JSON模式与thinking选项。提供方与接口只读，避免把原凭据转发到另一端点。只显示“凭据已配置”，不解析或显示密钥/句柄。API Key仍由 configure-model.py 在本机隐藏录入。

带 -Profile 时更新该profile的模型参数，并保留其他配置；缺省值来自var/config/model.json。不带 -Profile 则编辑共享模型配置。保存使用版本摘要、锁与原子替换；检测到他人修改会拒绝覆盖。新参数需要重启对应服务才生效，TUI不自动重启。
